# OmiReminder

OmiReminder is a simple reminder app designed to run locally and stay in the system tray. It will notify users about upcoming events and tasks that need attention soon.

## Planned technology stack

- Electron, React.js, and TypeScript for the desktop frontend
- Express.js for the backend API
- MongoDB for data storage

## Project structure

- `frontend/` — desktop interface and Electron app
- `backend/` — API and data access

The application is in its initial planning stage.
